# 项目总览

内容工坊是一款面向运营人员的内容活动规划Agent，以活动主题、制作预算和截止时间为输入，完成需求澄清、计划生成、素材检索、文案编写、成本与排期估算、方案校验和保存。用户通过聊天确认执行，也可修改需求、停止任务或从失败处继续。缺少必填信息时，集中追问并等待明确回复。

前端采用React、Vite和Ant Design，提供历史会话、聊天、计划与方案三栏工作台。后端使用FastAPI和PostgreSQL，通过LangGraph对话图与执行图组织任务。业务工具经MCP接入，模型支持Ollama Qwen3与DeepSeek，联网素材由Tavily检索，Skill按需提供策划、写作和交付规范。

系统根据实际工具结果调整计划。预算10、初始估算12时，模型选择替代规格并重新估算为8，校验通过后保存；没有可行方案则说明未完成原因和已知缺口。制作预算与工具、模型费用分别记录。

计划版本、工具尝试和成功产物持久化保存，支持结果复用、失败续跑与重复执行去重。页面实时展示步骤、输入输出、费用和来源，方案支持Markdown、JSON导出。当前版本面向本地单用户，采用两种制作套餐与串行排期，文案事实仍需人工审核。
