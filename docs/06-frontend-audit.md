# 前端检查

使用Chromium打开Vite工作台，连接FastAPI、PostgreSQL和Ollama Qwen3。5项完整UI用例、4项只读复验以及原有5项浏览器回归通过。这里的材料没有用 `/demo` 替代后端。

[完整报告](../examples/ui-label-audit/test-results/report.json) · [只读复验](../examples/ui-label-audit/recheck-report.json) · [基础回归](../examples/test-results/playwright.json)

## 检查内容

从浏览器新建会话，分次补充需求，先查看计划，再发送执行指令。成本由12调整为8后保存，刷新页面仍能读取。否定执行消息不会启动任务。

界面检查覆盖1440、1280、1024、390和320像素宽度，包括工具结果、费用、来源、日期时间、历史版本、文档阅读、复制和两种导出格式。下载正文与数据库方案逐项比较；剪贴板的LF/CRLF差异按等价文本处理。

## 修正的问题

| 问题 | 处理 |
| --- | --- |
| 工具输出直接显示英文键和枚举 | 字段、规格、来源与Skill名称使用中文标签，原值保留在数据中 |
| 合成素材url为空，却显示等待结果 | 改为无外部链接；未提供与正在返回分开显示 |
| 查看旧版仍显示新版成本和排期 | 按选中计划读取估算，旧版显示12/10，新版显示8/10 |
| 方案版本与所属计划版本容易混淆 | 同时显示方案版本和计划归属，旧计划标已被替代 |
| 调用成功与方案可行混在一起 | 保留调用完成状态，另显示预算/截止时间是否满足 |
| 无执行步骤的Skill卡片仍有定位入口 | 显示对话准备，有实际步骤时才提供定位 |
| 标签偏小、对比度不足 | 调整字号与颜色；所测关键标签对比度不低于4.5、字号不低于11px |
| 新建会话的辅助名称混入图标英文 | 设置中文名称，装饰图标不进入阅读名称 |
| 北京时间被模型解析为无时区，反复追问 | 核对原文后补正完整本地时间，不为仅日期的输入补造时刻 |
| 复制产生Ant Design上下文警告 | 使用App上下文消息，操作后无控制台警告 |

少量版本选项关闭虚拟隐藏，确保真实选项可访问。放大阅读、关闭、复制和导出都做了浏览器检查。该检查不等同于整站无障碍认证。

## 复现

按README启动服务，选择本地Qwen配置，先运行 `scripts/verify_live.py` 生成当前数据库中的测试会话：

```powershell
npm run test:ui:live
$env:LIVE_E2E='1'
npm run test:e2e
```

只读检查可以运行 `node scripts/inspect_ui_labels.cjs`。`AUDIT_STAGE=after` 用于指定修正后输出目录。新数据库需要先生成会话，旧JSON文件里的ID不能直接打开。

这组素材标签测试使用合成资料；外部来源和DeepSeek页面检查见[外部测试](11-external-live-and-review.md)。尚未覆盖超长历史列表、全部随机模型输出或完整文案事实核查。
